## 尚存风险与限制

1. 当前 `.env` 的模型 provider 为 disabled。需要配置真实服务，保存脱敏调用证据，再完成质量评估、真实失败案例与后期回测。无需把密钥发到聊天。
2. 现代模型可能记忆后期论文；本实验只能称为可能存在训练泄漏的历史覆盖回测。当前算法输出缺覆盖单元及启发式评分，不会自动发现一个新模型机制。
3. 原本前端依赖审计发现 23 项公告。本次移除未使用的 react-pdf/pdfjs-dist，并应用兼容范围修复；最终 npm 官方审计仍有 **18 项（1 moderate、16 high、1 critical）**，集中于旧 Electron、打包链、Vite 和 lint 相关依赖。消除这些需要单独的大版本迁移及 Electron 打包/运行回归，本次未强制迁移；不建议据此进行对外生产发布。完整公告与修复版本见 `npm-audit.json`。
4. 账户为本地文件、会话为内存；没有企业身份提供商。测试/演示默认账号只适用于本地课程环境。
5. 领域包绑定与待入库队列仍有浏览器本地状态；没有跨设备同步。
6. PDF 文件归档与图数据库不是分布式事务：失败回滚后可能有孤立归档文件，API 因无论文归属不会提供访问。需另制定长期清理与删除保留策略。
7. pypdf 没有精确裁图位置；保留完整 PDF 可供人工复核。扫描图像与复杂表格仍依赖单独配置 Marker/OCR 和质量核验。
