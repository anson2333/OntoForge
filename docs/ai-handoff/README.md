# OntoForge 后续 AI 工作入口

更新时间：2026-10-30。

## 从哪里开始

1. 先完整阅读 [实施主指南](../../后续开发指南.md)。
2. 再阅读 [路线概览](../superpowers/plans/2026-10-30-ontology-research-roadmap.md)。两者冲突时，以本目录实施主指南的目标边界和最新用户指令为准；旧路线主要解释设计理由。
3. 对照实际代码确认当前状态，再执行主指南中的第一个未完成阶段。文档勾选不等于代码已实现。
4. 每完成一个阶段，更新主指南末尾的交接记录：改动、测试、数据、限制和下一步。

## 核心目标

实现原课程要求中的**领域文献摄取 → 语义实体与关系 → 形式化图/本体 → 可解释的研究空白候选**。

复杂度重点是**形式化模式、实体消解、知识表示、图论抽象**。不要将主要开发时间转移到通用聊天、开放式代码执行、自动训练模型或美化页面。

## 可直接复制给后续 AI 的任务说明

> 请先完整阅读 后续开发指南.md，检查现有代码与交接状态。以原课程的语义和知识复杂性要求为目标，保留已有前后端、认证、Neo4j及历史实测结果。从第一个未完成阶段开始，先实现并验证领域模式、实体消解和实验身份，再推进图上的空白候选，最后接Assistant调度。每阶段提供真实测试和可追溯案例，不以模型自评冒充人工核验，不删除既有工作区，不调用其他模型提供商。除非我另有指示，本次先完成主指南的P0和P1，并更新交接记录；不要一次扩展成通用科研Agent。

以上提示的执行范围以实际用户消息为准，文件本身不授予联网、付费调用、删除、迁移或其他超出会话授权的权限。
