# OntoForge CV 目标检测课程范围

## 目标

本课程版本只处理目标检测论文中的模型、组件、数据集划分、实验、准确率与推理速度。系统从固定 PDF 版本抽取候选事实，经过类型约束、实体消解、字段证据检查和人工审核后形成 Neo4j 属性图，并在**当前工作区语料范围内**生成可解释的研究空白候选。

本项目不声称运行 OWL 推理机，不自动训练检测模型，也不把“当前导入论文中未找到”写成“整个领域无人研究”。LLM 输出、程序检查和真实人工审核使用不同状态。

## 必须回答的能力问题

1. `VGG-16` 与 `VGG16` 为什么是同一 Backbone？
2. `Fast R-CNN` 与 `Faster R-CNN`、检测器与 RPN 为什么不能合并？
3. 一条测量如何回溯到模型变体、训练/测试集、抽取运行和 PDF 证据？
4. 两个实验按准确率或速度策略是否可比，哪些字段相同、冲突或未决？
5. 一个空白候选由哪些已知路径和缺失关系产生，质量门槛、语料范围和下一步反证问题是什么？

## 数据与评价边界

- 开发样本：Fast R-CNN、Faster R-CNN、YOLO v1。它们参与过规则调整，不能作为留出成绩。
- 留出清单：`docs/cv-validation/corpus.json` 中标记为 `holdout` 的 7 篇 v1 PDF；只有成员固定文件哈希并人工标注后才能用于质量结论。
- 现有 8 条展示记录是 AI 辅助核对材料，不是人工 gold。
- 实体消解、实验元组、字段证据、拒答覆盖和空白候选分别评价，不以一个总分掩盖错误合并。
